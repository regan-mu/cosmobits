# Requirements Document

## Introduction

This document defines the requirements for polishing the CosmoBits Technologies landing page by removing AI-generated aesthetic patterns (spinning icons, particles, pulsing glows, parallax effects), replacing buzzword-heavy copy with professional direct language, integrating AOS (Animate on Scroll) for lightweight scroll-triggered animations, and preserving the existing brand identity (purple palette, dark sections, modern feel).

## Glossary

- **Landing_Page**: The public-facing single page at `src/app/page.tsx` composed of discrete React section components (Hero, Partners, About, WhyUs, AISection, Services, Testimonials, CTA, Contact, Footer)
- **Infinite_Animation**: Any CSS or framer-motion animation with `repeat: Infinity` or CSS `animation-iteration-count: infinite` that loops perpetually
- **Entrance_Animation**: A one-time animation triggered when an element first enters the viewport or when the page loads
- **AOS**: Animate on Scroll library — a lightweight CSS-based scroll animation library using `data-aos` HTML attributes
- **Framer_Motion**: The existing React animation library used for programmatic animations, hover interactions, and layout transitions
- **Pulsing_Glow**: An animation that cyclically increases and decreases `boxShadow` spread, `opacity`, or `scale` with infinite repetition
- **Parallax_Effect**: Interactive movement of background elements in response to mouse position tracking
- **Buzzword_Copy**: Marketing text containing vague, hyperbolic, or fear-mongering phrases commonly generated by AI templates (e.g., "Supercharge", "Revolution", "Transform", "Journey", "Unlock Potential")
- **Brand_Identity**: The existing visual identity including purple color palette, dark section backgrounds, modern typography, and professional tone
- **Marquee_Animation**: The continuous horizontal scroll animation in the Partners component for logo display
- **CounterAnimation**: The scroll-triggered number counting animation in the About section

## Requirements

### Requirement 1: Remove Infinite Spinning Animations

**User Story:** As a site visitor, I want the landing page to feel hand-crafted and professional, so that I trust CosmoBits as a credible technology partner.

#### Acceptance Criteria

1. WHEN the Landing_Page renders, THE Hero component SHALL display the Brain icon without any rotation animation
2. WHEN the Landing_Page renders, THE AISection component SHALL display the Brain icon without any rotation animation
3. WHEN the Landing_Page renders, THE Hero component SHALL display orbital rings as stationary decorative circles without rotation
4. THE Landing_Page SHALL contain zero framer-motion elements with `animate={{ rotate: 360 }}` or `animate={{ rotate: -360 }}` combined with `repeat: Infinity`

### Requirement 2: Remove Decorative Particle and Orb Elements

**User Story:** As a site visitor, I want the page to load quickly and look clean, so that I can focus on the content without visual noise.

#### Acceptance Criteria

1. WHEN the Hero component renders, THE Landing_Page SHALL not display any FloatingParticle elements
2. WHEN the Hero component renders, THE Landing_Page SHALL not display any AIOrb elements
3. THE Hero component source file SHALL not contain declarations for FloatingParticle, AIOrb, or particleConfigs
4. WHEN the Hero component renders, THE Landing_Page SHALL not display animated SVG neural network line decorations

### Requirement 3: Remove Pulsing Glow Animations

**User Story:** As a site visitor, I want a calm, professional visual experience, so that the page does not feel like an AI-generated template.

#### Acceptance Criteria

1. WHEN the Hero component renders, THE center logo element SHALL display a single static box-shadow instead of a cycling Pulsing_Glow
2. WHEN the Hero component renders, THE inner glow circle SHALL display a single static box-shadow instead of a cycling Pulsing_Glow
3. WHEN the AISection component renders, THE background blob elements SHALL use static opacity and scale instead of infinite pulsing
4. WHEN the AISection heading renders, THE blur element behind the "AI" text SHALL not animate opacity
5. WHEN the CTA component renders, THE background blob elements SHALL not use infinite scale or opacity cycling
6. WHEN the CTA component renders, THE trust indicator dots SHALL not use the `animate-pulse` CSS class
7. WHEN the WhyUs component renders, THE first card overlay SHALL not use the `animate-pulse` CSS class
8. THE Landing_Page SHALL contain zero decorative elements using `animate-pulse` CSS class or framer-motion cycling `boxShadow`/`opacity` with `repeat: Infinity`

### Requirement 4: Remove Mouse Parallax Tracking

**User Story:** As a site visitor on a desktop device, I want gradient orbs to remain fixed, so that the page feels stable and does not react distractingly to my cursor.

#### Acceptance Criteria

1. THE Hero component SHALL not contain a `mousePosition` state variable
2. THE Hero component SHALL not attach a `mousemove` event listener
3. WHEN the Hero component renders, THE gradient orb elements SHALL use fixed CSS positioning without transform values derived from mouse coordinates

### Requirement 5: Replace Buzzword Copy with Professional Language

**User Story:** As a site visitor, I want clear and honest messaging, so that I understand what CosmoBits actually offers without hype.

#### Acceptance Criteria

1. WHEN the Hero component renders, THE main heading SHALL use direct professional language without multiple AI buzzwords
2. WHEN the Hero component renders, THE primary CTA button SHALL display actionable text such as "Get in Touch" instead of "Unlock AI Potential"
3. WHEN the Hero component renders, THE stats section SHALL label support as "Technical Support" instead of "AI Support"
4. WHEN the AISection component renders, THE heading SHALL use restrained language instead of "Supercharge Your Business with AI"
5. WHEN the AISection component renders, THE description copy SHALL state factual value propositions instead of fear-mongering language
6. WHEN the AISection component renders, THE CTA button SHALL display "Book a Free Consultation" instead of "Start Your AI Journey"
7. WHEN the CTA component renders, THE heading SHALL use direct language such as "Let's Talk About Your Next Project" instead of "Let's Build the Future"
8. WHEN the CTA component renders, THE primary button SHALL display "Schedule a Call" instead of "Start Your AI Journey"
9. WHEN the Contact component renders, THE heading SHALL display "Get in Touch" instead of "Let's Build Something Amazing Together"
10. WHEN the Footer component renders, THE newsletter heading SHALL display "Stay in the Loop" instead of "Stay Updated with AI Trends"
11. WHEN the Partners component renders, THE section label SHALL display "Our Partners" instead of "Trusted by Leading Organizations"

### Requirement 6: Replace Animated CTA Background with Static Gradient

**User Story:** As a site visitor, I want the call-to-action section to feel calm and focused, so that I am drawn to the action button rather than distracted by a moving background.

#### Acceptance Criteria

1. WHEN the CTA component renders, THE background SHALL use a static gradient instead of the `animate-gradient-x` animated gradient
2. THE CTA component source file SHALL not reference the `animate-gradient-x` CSS animation class

### Requirement 7: Reduce Excessive Hover Micro-Interactions

**User Story:** As a site visitor, I want hover effects that feel purposeful, so that interactions feel polished rather than gimmicky.

#### Acceptance Criteria

1. WHEN a user hovers over a WhyUs card, THE card SHALL translate vertically by no more than 5px and SHALL not apply a scale transform
2. WHEN a user hovers over an AISection service card icon, THE icon SHALL not rotate
3. WHEN a user hovers over a Services card icon, THE icon SHALL scale by no more than 1.05 and SHALL not rotate
4. WHEN a user hovers over a Services card icon, THE decorative radial gradient circle element SHALL not be present in the card

### Requirement 8: Reduce Neon Glow on CTA Buttons

**User Story:** As a site visitor, I want buttons to look professional, so that the page does not feel like a sci-fi template.

#### Acceptance Criteria

1. WHEN the AISection CTA button renders, THE box-shadow spread SHALL not exceed 20px
2. THE CTA badge element with generic text "Ready to Transform Your Business?" SHALL be removed entirely from the CTA component

### Requirement 9: Install and Initialize AOS Library

**User Story:** As a developer, I want a lightweight scroll animation library, so that entrance animations work without heavy framer-motion viewport wrappers.

#### Acceptance Criteria

1. THE project dependencies SHALL include the `aos` package
2. THE project devDependencies SHALL include the `@types/aos` package
3. WHEN the application mounts, THE AOSInit component SHALL call `AOS.init()` with duration between 600ms and 800ms, `once` set to true, and offset between 100px and 120px
4. THE AOSInit component SHALL be rendered within the Providers component in `layout.tsx`
5. THE AOSInit component SHALL import the AOS CSS file (`aos/dist/aos.css`)

### Requirement 10: Replace Framer-Motion Scroll Animations with AOS

**User Story:** As a developer, I want to use simple data attributes for scroll animations, so that component code is cleaner and bundle size is reduced.

#### Acceptance Criteria

1. WHEN a section below the Hero enters the viewport, THE section content SHALL animate using AOS `data-aos` attributes instead of framer-motion `whileInView` props
2. THE Hero component SHALL not contain any `data-aos` attributes because the Hero uses framer-motion immediate entrance animation on page load
3. WHEN AOS animations are applied, THE allowed animation values SHALL be limited to "fade-up", "fade-in", "fade-right", and "fade-left"
4. WHEN card grids use staggered AOS animations, THE maximum `data-aos-delay` value SHALL not exceed 400ms
5. WHEN an element requires both scroll entrance and hover interaction, THE element SHALL use an outer div with `data-aos` and an inner `motion.div` with `whileHover`

### Requirement 11: Preserve Framer-Motion for Non-Scroll Animations

**User Story:** As a developer, I want to keep framer-motion where it adds value, so that hover interactions, the marquee, and counter animations continue working.

#### Acceptance Criteria

1. THE Partners component SHALL continue using framer-motion for the Marquee_Animation
2. THE CounterAnimation component SHALL continue using framer-motion for number counting animation
3. WHEN a component has hover interactions using `whileHover` or `whileTap`, THE component SHALL retain those framer-motion props
4. THE Hero component SHALL retain its framer-motion `initial`/`animate` entrance animation for immediate page-load appearance

### Requirement 12: Remove Unused CSS Animation Keyframes

**User Story:** As a developer, I want the CSS to only contain animation definitions that are actively used, so that the stylesheet is clean and maintainable.

#### Acceptance Criteria

1. IF the `@keyframes ai-pulse` rule is not referenced by any component after fixes, THEN THE globals.css file SHALL not contain that keyframe definition
2. IF the `@keyframes pulse-glow` rule is not referenced by any component after fixes, THEN THE globals.css file SHALL not contain that keyframe definition
3. IF the `.animate-ai-pulse` utility class is not referenced by any component after fixes, THEN THE globals.css file SHALL not contain that class definition
4. THE `.glow-ai` class in globals.css SHALL have its box-shadow reduced to no more than 20px spread or be removed entirely if unused

### Requirement 13: Clean Up Unused Imports

**User Story:** As a developer, I want no dead code in component files, so that the codebase is clean and IDE warnings are eliminated.

#### Acceptance Criteria

1. WHEN the Partners component is modified, THE source file SHALL not contain unused icon imports (Building2, Landmark, Factory, Store, Globe, Shield)
2. WHEN the CTA component is modified, THE source file SHALL replace the Rocket icon import with ArrowRight if the Rocket icon is no longer used in the render
3. WHEN the Hero component is modified, THE source file SHALL not contain unused imports for removed elements (Sparkles, Zap, or other icons no longer rendered)

### Requirement 14: Preserve Brand Identity

**User Story:** As a brand stakeholder, I want the landing page to maintain our established visual identity, so that the polish does not feel like a redesign.

#### Acceptance Criteria

1. THE Landing_Page SHALL continue using the purple color palette defined by CSS custom properties in globals.css
2. THE Landing_Page section backgrounds SHALL remain dark-themed using the existing primary-dark, primary-medium, and primary-light color variables
3. THE Landing_Page SHALL continue using the ByteSharp display font and UniSans body font as defined in the existing font configuration
4. WHEN animations are removed, THE Landing_Page layout and spacing SHALL remain unchanged with no visual shift in element positioning

### Requirement 15: Remove Hero Scroll Indicator Bounce Animation

**User Story:** As a site visitor, I want the scroll indicator to be visible without bouncing, so that the page feels restrained.

#### Acceptance Criteria

1. WHEN the Hero component renders a scroll indicator element, THE element SHALL be visible without a repeating vertical bounce animation
2. THE scroll indicator SHALL remain present in the DOM as a static element
